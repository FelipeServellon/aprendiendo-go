# aprendiendo-go

Registro de mi aprendizaje de Go desde cero. Cada carpeta es un ejercicio; el historial de commits muestra el avance.

| Ejercicio | Tema |
|---|---|
| `ejercicio1` | Primer programa |
| `ejercicio2` | Funciones, parámetros y múltiples retornos |
| `ejercicio3` | Slices, `make`, `append`, módulo `%` |
| `ejercicio4` | Búsqueda en slices y structs |
| `ejercicio5` | Filtrado de structs |
| `ejercicio6` | Maps: sumar, contar, filtrar *(en progreso)* |
| `ejercicio7` | Maps y structs: agrupar, filtrar, quitar repetidos |
| `ejercicio8` | Quitar repetidos con maps |
| `ejercicio9` | Structs, promedios y repetidos |

## Ejecutar

```bash
go run ./trabajo/ejercicio4
go test ./trabajo/ejercicio6
```
